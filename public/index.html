Contacts

Fields tracked today: email, phone, company/title, date of birth, address, and spouse (inferred from "spouse" relationships). School, past employers, and anniversaries aren't captured as structured fields yet — add them as notes on a contact, or ask to have dedicated fields added.

Settings

Who are you?

Pick which contact represents you. Once set, your connections to everyone else are highlighted as "You" throughout the app.

Import contacts

Import people from Google Contacts or Apple Contacts. Export your contacts as a vCard (.vcf) file from either service, then upload it here. Contacts are matched by email — duplicates are skipped automatically.

Google Contacts: Export → vCard (.vcf). Apple Contacts (macOS): select contacts → File → Export → Export vCard.

Bulk import relationships

Add many relationships (edges) at once between contacts that already exist. Upload a CSV with columns source,target,type,notes — one row per relationship. People are matched by exact email or exact name; a person can appear in as many rows as needed, so many-to-many connections are just multiple rows.

Example:
source,target,type
Jane Doe,John Smith,colleague
Jane Doe,jane@example.com,friend
John Smith,jane@example.com,knows

Security

You sign in with a passkey. Passkey management (adding a second device, removing this one) isn't built yet — for now there's a single passkey tied to your contact. Use the "Log out" button in the top bar to end your session.

API keys

Create named keys for accessing this CRM's HTTP API directly (e.g. with curl or a script) or via the graph-crm MCP server used by Claude — both authenticate by sending Authorization: Bearer <key>. Each key bypasses passkey login. A key's full value is shown once, right after you create it — after that only its label and prefix are shown, so keep a copy somewhere safe.
